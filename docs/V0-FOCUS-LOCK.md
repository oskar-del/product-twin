# Product Twin V0 · Focus Lock

## Why this exists

Product Twin has generated strong adjacent ideas. They are preserved in `docs/IDEA-PARKING.md`, but V0 stays focused on the original loop:

`REAL PRODUCT / SYSTEM → CANONICAL IDENTITY → VERIFIED DIGITAL AVATAR → PROJECT PLACEMENT → TECHNICAL / REGULATORY FIT → LIVE OFFER OR RFQ → PROCUREMENT`

New major product branches remain parked until the exit criteria below are met.

## Pillar 3 · End-to-end Product Twin proof

Use one room / compact house scene, not another broad feature demo.

The proof must contain real Product Twins from multiple categories and demonstrate:

1. Product discovery.
2. Canonical identity resolution.
3. Avatar loading at verified scale.
4. Placement in the scene.
5. Exact-product vs proxy disclosure.
6. Technical compatibility gate.
7. Regulatory/location gate where relevant.
8. Live price/availability refresh.
9. Substitute / cheaper alternative.
10. Same-transform swap.
11. Budget update.
12. Merchant cart or RFQ handoff.
13. Persistent reference without caching prohibited marketplace payloads.

### End-to-end exit criterion

At least one visible object must successfully travel:

`LIVE PRODUCT → PRODUCT TWIN ID → VERIFIED AVATAR → PROJECT PLACEMENT → SWAP/COMPARE → CURRENT OFFER → CART/RFQ`

without a fake product identity, fake geometry claim or stale cached commerce data.

## Parked until V0 core exit criteria are met

Keep existing prototypes and schemas, but do not significantly deepen them yet:

- Performance Graph / acoustics.
- Developer delivery / B2B orbit.
- Advanced construction timeline.
- Full operations / facility management.
- Large prefab tender marketplace.
- Large showroom catalogue expansion.

The Showroom and Project Lens may be used only as presentation surfaces for the core Product Twin proof.

## Working rule

When a new idea appears, add it to `docs/IDEA-PARKING.md`, then ask:

> Does this directly improve source coverage, canonical identity, avatar quality, project compatibility, or the live procurement loop?

If no, park it until V0 core completion.
